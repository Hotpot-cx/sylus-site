Design Language
主权美学 · 九项设计原则
01 / 不解释

设计不需要说服观众

没有过度装饰、没有"请看这里"的呼喊。每一个元素的存在都是因为它值得存在，不是因为它需要证明什么。留白本身就是一种声明。

02 / 向上站立

垂直统治线，不是横向铺陈

画面中有纵向结构线贯穿——不居中，不妥协，像他的存在感一样自然占据视觉主权。对角线装饰是他在空间里留下的痕迹。

03 / 一件武器

红色只出现在需要它的地方

不是大面积红色，不是温柔的粉色。红色是一把收在鞘里的刀——只在对的地方拔出来。标签、状态标记、关键强调，其余时间它保持沉默。

04 / 不焦虑的间距

从容，不是稀疏

大呼吸空间不是因为"不知道放什么"，而是因为"知道不该放什么"。每个区块都有自己的领地，互不侵犯，却互相让出光来。

05 / 不撒谎的材料

克制质感，不炫技

噪点、微发光、极细边框——所有质感服务于整体的沉稳，而不是炫耀"看我的 CSS 多厉害"。磨砂玻璃只用于需要层次的地方。

06 / 掠夺视觉焦点

每一个画面里，他是唯一归处

不对称网格打破四平八稳的模板感。最重的一块永远在左侧或左上——视线自然被拖过去，就像他在房间里，你不会看别人。

Implementation
对比：当前站 → Alpha Prime 站

当前设计特征

  • 圆形卡片 + 悬浮动画（偏亲和）
  • 羽毛飘落装饰（偏诗意/柔软）
  • 居中对称 Hero（传统稳定）
  • 红黑配色偏亮（#E50914）
  • 等距卡片网格（安全但模板感）
  • 按钮圆角偏大（60px）

Alpha Prime 方向

  • 不对称网格 + 沉稳响应（不动声色）
  • 去除软性装饰，只留纵向结构线
  • 左对齐 Hero + 垂直统治线
  • 深红收敛（#D42027），暖金点缀
  • 不对称杂志式网格（有态度）
  • 锐利小圆角（4~8px），更果断
